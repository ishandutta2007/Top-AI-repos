## 📂 Category Breakdown

### Image Generation & Studio GUIs

- **[Stable Diffusion web UI](https://github.com/AUTOMATIC1111/stable-diffusion-webui)** (Python): A browser interface based on the Gradio library for Stable Diffusion.
- **[ComfyUI](https://github.com/comfyanonymous/ComfyUI)** (Python, Javascript): The most powerful and modular stable diffusion GUI, api and backend with a graph/nodes interface.
- **[CompVis Stable Diffusion (original)](https://github.com/CompVis/stable-diffusion)** (Python (Jupyter Notebook)): A Python library for diffusion modeling, a type of generative model that can be used to create images, text, and other types of data.
- **[huggingface diffusers](https://github.com/huggingface/diffusers)** (Python): Open-source project
- **[InvokeAI](https://github.com/invoke-ai/InvokeAI)** (Typescript): InvokeAI is a leading creative engine for Stable Diffusion models, empowering professionals, artists, and enthusiasts to generate and create visual media using the latest AI-driven technologies
- **[Stability-AI generative-models](https://github.com/Stability-AI/generative-models)** (Python): Open-source project
- **[FLUX](https://github.com/black-forest-labs/flux)** (Python): Official inference repo for FLUX.1 models
- **[Sanster/lama-cleaner](https://github.com/Sanster/lama-cleaner)** (Python): Image inpainting tool powered by SOTA AI Model.
- **[Deepfacelab](https://github.com/iperov/DeepFaceLab)** (Python): software for creating deepfakes
- **[Apple Stable Diffusion](https://github.com/apple/ml-stable-diffusion)** (Python): Stable Diffusion with Core ML on Apple Silicon
- **[Dall E Mini](https://github.com/borisdayma/dalle-mini)** (Python): Open-source project
- **[Kohya_UI](https://github.com/bmaltais/kohya_ss)** (Python): Windows-focused Gradio GUI for Kohya's Stable Diffusion trainers
- **[deep-floyd - IF](https://github.com/deep-floyd/IF)** (Python): text-to-image model with a high degree of photorealism and language understanding

### Speech Recognition & Audio

- **[whisper](https://github.com/openai/whisper)** (Python): Robust Speech Recognition via Large-Scale Weak Supervision
- **[Whisper.cpp](https://github.com/ggerganov/whisper.cpp)** (Python): Open-source project
- **[Coqui-AI TTS](https://github.com/coqui-ai/TTS)** (Python): Aadvanced Text-to-Speech generation in 1100+ languages.
- **[fish-speech](https://github.com/fishaudio/fish-speech)** (Python): State-of-the-art open-source text-to-speech and voice cloning model.
- **[Zyphra Zonos](https://github.com/Zyphra/Zonos)** (Python): TTS

### Computer Vision & Segmentation

- **[Segment Anything](https://github.com/facebookresearch/segment-anything)** (Python): Open-source project
- **[Detectron2](https://github.com/facebookresearch/detectron2)** (Python): A modular, scalable, and extensible object detection and segmentation framework.
- **[IDEA-Research/Grounded-Segment-Anything](https://github.com/IDEA-Research/Grounded-Segment-Anything)** (Python): Marrying Grounding DINO with Segment Anything & Stable Diffusion & Recognize Anything
- **[Yolo7](https://github.com/WongKinYiu/yolov7)** (Python (Jupyter Notebook)): Open-source project

### Multimodal Systems

- **[TaskMatrix](https://github.com/moymix/TaskMatrix)** (Python): TaskMatrix connects ChatGPT and a series of Visual Foundation Models to enable sending and receiving images during chatting

### 3D & Video Synthesis

- **[Stable Dreamfusion](https://github.com/ashawkey/stable-dreamfusion)** (Python): A pytorch implementation of the text-to-3D model Dreamfusion, powered by the Stable Diffusion text-to-2D model
- **[LatentSync](https://github.com/bytedance/LatentSync)** (Markdown): AI Notes
- **[Step-Video-T2V](https://github.com/stepfun-ai/Step-Video-T2V)** (Markdown): AI Notes
