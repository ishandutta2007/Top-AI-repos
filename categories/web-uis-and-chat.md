## 📂 Category Breakdown

### Self-Hosted Web Chat UIs

- **[open-webui](https://github.com/open-webui/open-webui)** (JavaScript): User-friendly AI Interface (Supports Ollama, OpenAI API, ...)
- **[ChatGPT Next Web](https://github.com/Yidadaa/ChatGPT-Next-Web)** (Typescript): cross-platform ChatGPT UI
- **[nanochat](https://github.com/karpathy/nanochat)** (Python): The best ChatGPT that $100 can buy.
- **[LibreChat](https://github.com/danny-avila/LibreChat)** (Typescript, Javascript): Enhanced ChatGPT Clone
- **[Open Assistant](https://github.com/LAION-AI/Open-Assistant)** (Python): chat-based assistant that understands tasks, can interact with third-party systems, and retrieve information dynamically to do so
- **[Huggingface Chat-UI](https://github.com/huggingface/chat-ui)** (Typescript): HuggingChat app

### Desktop & Specialized Chat Clients

- **[Gpt Academic](https://github.com/binary-husky/gpt_academic)** (Python): practical interactive interface for ChatGPT/GLM, specially optimizes the paper reading/polishing/writing experience, modular design, supports custom shortcut buttons & function plug-ins, supports Python and C++ and other project analysis & self-interpretation functions, PDF/LaTex papers The translation & summary function supports parallel query of multiple LLM models, and supports local models such as chatglm2. Compatible with Wen Xin Yi Yan, moss, llama2, rwkv, claude2, Tongyi Qianwen, Scholar, iFlytek Spark, etc.
- **[anything-llm](https://github.com/Mintplex-Labs/anything-llm)** (JavaScript): Stop renting your intelligence. Own it with AnythingLLM. Everything you need for a powerful local-first agent experience.
- **[cherry-studio](https://github.com/CherryHQ/cherry-studio)** (TypeScript): AI productivity studio with smart chat, autonomous agents, and 300+ assistants. Unified access to frontier LLMs.
- **[Jan](https://github.com/janhq/jan)** (TypeScript): Jan is an open source alternative to ChatGPT that runs 100% offline on your computer.
- **[SillyTavern](https://github.com/SillyTavern/SillyTavern)** (JavaScript): LLM Frontend for Power Users.
- **[ChatALL](https://github.com/sunner/ChatALL)** (Javascript): Open-source project
