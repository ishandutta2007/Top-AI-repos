## 📂 Category Breakdown

### Visual Workflow Automation

- **[n8n](https://github.com/n8n-io/n8n)** (TypeScript): Fair-code workflow automation platform with native AI capabilities.
- **[langflow](https://github.com/langflow-ai/langflow)** (Python): Langflow is a powerful tool for building and deploying AI-powered agents and workflows.
- **[Dify](https://github.com/langgenius/dify)** (TypeScript): Production-ready platform for agentic workflow development.
- **[Flowise](https://github.com/flowiseai/Flowise)** (TypeScript): Build AI Agents, Visually

### LLM Orchestration Frameworks

- **[Langchain](https://github.com/langchain-ai/langchain)** (Python, MDX): framework designed to simplify the creation of applications using large language models. As a language model integration framework, LangChain's use-cases largely overlap with those of language models in general, including document analysis and summarization, chatbots, and code analysis.
- **[LangGraph](https://github.com/langchain-ai/langgraph)** (Python, TypeScript): A library for building stateful, multi-actor applications with LLMs, specifically designed to handle cyclical/graph-based agent workflows that traditional linear pipelines struggle with.
- **[LangChain.js](https://github.com/langchain-ai/langchainjs)** (TypeScript): The agent engineering platform

### Protocols & Integration Standards

- **[modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)** (Multiple): A collection of reference implementations for the Model Context Protocol and community-built servers.

### Prompt Programming & DSP

- **[DSPy](https://github.com/stanfordnlp/dspy)** (Python): The framework for programming—not prompting—language models.
- **[AdalFlow](https://github.com/SylphAI-Inc/AdalFlow)** (Python): The library to build & auto-optimize LLM applications.
- **[EgoAlpha/prompt-in-context-learning](https://github.com/EgoAlpha/prompt-in-context-learning)** (Markdown): AI Notes

### Full-Stack & Web App Toolkits

- **[Vercel AI SDK](https://github.com/vercel/ai)** (TypeScript): The AI Toolkit for TypeScript. From the creators of Next.js, the AI SDK is a free open-source library for building AI-powered applications and agents.
- **[FastHTML](https://github.com/AnswerDotAI/fasthtml)** (Python): A lightweight framework for rapidly creating web apps for AI and data science.

### Structured Outputs & Generation Control

- **[outlines](https://github.com/dottxt-ai/outlines)** (Python): Structured text generation — force LLMs to output valid JSON, regex, or grammar-constrained text.
- **[instructor](https://github.com/instructor-ai/instructor)** (Python): Structured data extraction from LLMs — get validated, typed outputs from any LLM.
