## 📂 Category Breakdown

### Local Runtimes & Inference Engines

- **[Ollama](https://github.com/ollama/ollama)** (Go): Get up and running with large language models locally.
- **[Llama.cpp](https://github.com/ggerganov/llama.cpp)** (C,C++): Meta's LLaMA model in C/C++
- **[Gpt4all](https://github.com/nomic-ai/gpt4all)** (C++,QML): LLM chatbots that you can run anywhere
- **[Local AI](https://github.com/go-skynet/LocalAI)** (Go, Python): LocalAI is a drop-in replacement REST API compatible with OpenAI API specifications for local inferencing. It allows to run models locally or on-prem with consumer-grade hardware, supporting multiple models families compatible
- **[llamafile](https://github.com/mozilla-ai/llamafile)** (C++): A framework that lets you distribute and run LLMs with a single file by combining llama.cpp with Cosmopolitan Libc.
- **[Llama2.c](https://github.com/karpathy/llama2.c)** (C, Python): Open-source project
- **[H2oGpt](https://github.com/h2oai/h2ogpt)** (Python): Open-source project

### Open Foundation Models

- **[DeepSeek-V3](https://github.com/deepseek-ai/DeepSeek-V3)** (Python): DeepSeek-V3 is a strong Mixture-of-Experts (MoE) language model.
- **[DeepSeek-R1](https://github.com/deepseek-ai/DeepSeek-R1)** (Python): DeepSeek-R1: A breakthrough reasoning model with chain-of-thought capabilities rivaling proprietary models.
- **[Llama](https://github.com/facebookresearch/llama)** (Python): Open-source project
- **[ChatGLM 6B](https://github.com/THUDM/ChatGLM-6B)** (Python): Open-source project
- **[Qwen2.5](https://github.com/QwenLM/Qwen2.5)** (Python): Alibaba's Qwen2.5 series of open-weight foundation models for language, code, and math.
- **[MiniGPT-4](https://github.com/Vision-CAIR/MiniGPT-4)** (Python): Open-source project
- **[Chinese LLaMA Alpaca](https://github.com/ymcui/Chinese-LLaMA-Alpaca)** (Python): Open-source project
- **[Stability-AI Stable LM](https://github.com/Stability-AI/StableLM)** (Python): Open-source project

### High-Throughput Production Serving

- **[vLLM](https://github.com/vllm-project/vllm)** (Python): A high-throughput and memory-efficient inference and serving engine for LLMs.
- **[airllm](https://github.com/lyogavin/airllm)** (Jupyter Notebook): An optimization tool for running 70B+ large language models on a single 4GB GPU without quantization or pruning.
- **[sglang](https://github.com/sgl-project/sglang)** (Python): SGLang is a high-performance serving framework for large language models and multimodal models.
- **[bentoml/BentoML](https://github.com/bentoml/BentoML)** (Python): The Unified AI Application Framework

### API Gateways & Unified Proxies

- **[Gpt4free](https://github.com/xtekky/gpt4free)** (Python): various collection of powerful language models
- **[Litellm](https://github.com/BerriAI/litellm)** (Python): Call all LLM APIs using the OpenAI format. Use Bedrock, Azure, OpenAI, Cohere, Anthropic, Ollama, Sagemaker, HuggingFace, Replicate (100+ LLMs)
