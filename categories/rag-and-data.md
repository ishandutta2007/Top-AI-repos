## 📂 Category Breakdown

### Web Scraping & Extraction

- **[firecrawl](https://github.com/mendableai/firecrawl)** (TypeScript): The API to search, scrape, and interact with the web at scale.

### RAG Pipelines & Engines

- **[RAGFlow](https://github.com/infiniflow/ragflow)** (Python): An open-source RAG engine based on deep document understanding.
- **[Embedchain](https://github.com/embedchain/embedchain)** (Python): Memory for AI agents
- **[privateGPT](https://github.com/imartinez/privateGPT)** (Python): Ask questions about your documents without an internet connection using the power of LLMs. 100% private; no data leaves your execution environment at any point. You can ingest documents and ask questions without an internet connection
- **[LlamaIndex](https://github.com/run-llama/llama_index)** (Python): Open-source project
- **[graphrag](https://github.com/microsoft/graphrag)** (Python): A modular graph-based Retrieval-Augmented Generation (RAG) system
- **[haystack](https://github.com/deepset-ai/haystack)** (Python): End-to-end framework for building composable RAG, search, and agentic AI pipelines.
- **[ChatGPT Retrieval](https://github.com/openai/chatgpt-retrieval-plugin)** (Python): Open-source project
- **[DB GPT](https://github.com/eosphoros-ai/DB-GPT)** (Python): Open-source project
- **[Azure search openai demo](https://github.com/Azure-Samples/azure-search-openai-demo)** (Python): Open-source project

### Document Parsing & OCR

- **[docling](https://github.com/DS4SD/docling)** (Python): Parse documents (PDF, DOCX, PPTX, etc.) into structured data for generative AI and RAG workflows.
- **[marker](https://github.com/VikParuchuri/marker)** (Python): Convert PDF, EPUB, and MOBI to Markdown quickly and accurately for LLM data pipelines.
- **[surya](https://github.com/VikParuchuri/surya)** (Python): Multilingual document OCR, layout analysis, reading order, and table recognition toolkit.

### Memory & Context Layers

- **[mem0](https://github.com/mem0ai/mem0)** (Python): The memory layer for personalized AI — add persistent, structured memory to your AI agents.
- **[MemGPT](https://github.com/cpacker/MemGPT)** (Python): Teaching LLMs memory management for unbounded context
- **[memU](https://github.com/NevaMind-AI/memU)** (Python): Memory for 24/7 proactive agents like moltbot (clawdbot).

### Vector Databases & Data Engines

- **[Milvus](https://github.com/milvus-io/milvus)** (Go): Open-source project
- **[Mindsdb](https://github.com/mindsdb/mindsdb)** (Python): Open-source project
- **[qdrant](https://github.com/qdrant/qdrant)** (Rust): High-performance vector similarity search engine and database for AI applications.
- **[Chroma](https://github.com/chroma-core/chroma)** (Python): Open-source project
- **[Weaviate](https://github.com/weaviate/weaviate)** (Go): Open-source project
