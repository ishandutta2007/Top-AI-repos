## 📂 Category Breakdown

### Deep Learning Frameworks

- **[tensorflow](https://github.com/tensorflow/tensorflow)** (C++): An Open Source Machine Learning Framework for Everyone.
- **[PyTorch](https://github.com/pytorch/pytorch)** (Python, C++): Tensors and Dynamic neural networks in Python with strong GPU acceleration
- **[Keras](https://github.com/keras-team/keras)** (Python): open-source library that provides a Python interface for artificial neural networks. Keras acts as an interface for the TensorFlow library. Up until version 2.3, Keras supported multiple backends, including TensorFlow, Microsoft Cognitive Toolkit, Theano, and PlaidML
- **[jax](https://github.com/jax-ml/jax)** (Python): Composable transformations of Python+NumPy programs: differentiate, vectorize, JIT to GPU/TPU, and more.
- **[Caffe](https://github.com/BVLC/caffe)** (C++): Open-source project
- **[PyTorch Lightning](https://github.com/Lightning-AI/lightning)** (Python): A lightweight PyTorch wrapper for high-performance AI research and production.
- **[MLX](https://github.com/ml-explore/mlx)** (C++): An array framework for machine learning on Apple Silicon by Apple.
- **[Fastai](https://github.com/fastai/fastai)** (Python (Jupyter Notebook)): Open-source project
- **[Apache Mxnet](https://github.com/apache/mxnet)** (C++, Python): Open-source project
- **[Triton](https://github.com/openai/triton)** (Python): Open-source project
- **[Convnetjs](https://github.com/karpathy/convnetjs)** (C, Python): Open-source project
- **[Theano](https://github.com/Theano/Theano)** (Python): Open-source project
- **[Sonnet](https://github.com/google-deepmind/sonnet)** (Python): Open-source project
- **[Tflearn](https://github.com/tflearn/tflearn)** (Python): Open-source project
- **[convnet-benchmarks](https://github.com/soumith/convnet-benchmarks)** (Python): Easy benchmarking of all publicly accessible implementations of convnets
- **[R-TensorFlow](https://github.com/rstudio/tensorflow)** (R): Open-source project

### Model Hubs & Foundational Libraries

- **[Hugging Face Transformers](https://github.com/huggingface/transformers)** (Python): A library of state-of-the-art pre-trained models for natural language processing (NLP).
- **[spaCy](https://github.com/explosion/spaCy)** (Python,MDX): An open-source library for natural language processing (NLP) in Python.
- **[Fairseq](https://github.com/facebookresearch/fairseq)** (Python): Open-source project
- **[openai-python](https://github.com/openai/openai-python)** (Python): The official Python library for the OpenAI API.
- **[Paddlenlp](https://github.com/PaddlePaddle/PaddleNLP)** (Python): Open-source project
- **[Deeppavlov](https://github.com/deeppavlov/DeepPavlov)** (Python): Open-source project

### Efficient Fine-Tuning & Training

- **[Unsloth](https://github.com/unslothai/unsloth)** (Python): 2-5x faster 70% less memory fine-tuning for LLMs.
- **[LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory)** (Python): Unified Efficient Fine-Tuning of 100+ LLMs & VLMs
- **[deepspeed](https://github.com/deepspeedai/deepspeed)** (Python): A deep learning optimization library that makes distributed training and inference easy, efficient, and effective.
- **[Huggingface PEFT](https://github.com/huggingface/peft)** (Python): State-of-the-art Parameter-Efficient Fine-Tuning
- **[mosaicml Composer](https://github.com/mosaicml/composer)** (Python): make GPT-4 fully autonomous
- **[MosiacML LLM Foundry](https://github.com/mosaicml/llm-foundry)** (Python): LLM training code for MosaicML foundation models
- **[LLM-Finetuning](https://github.com/ashishpatel26/LLM-Finetuning)** (Jupyter Notebook): LLM Finetuning with peft

### Classical Machine Learning

- **[Scikit-learn](https://github.com/scikit-learn/scikit-learn)** (Python): machine learning library for the Python programming language. It features various classification, regression and clustering algorithms including support-vector machines
- **[SciPy](https://github.com/scipy/scipy)** (Python, C): Open-source project
- **[CatBoost](https://github.com/catboost/catboost)** (Python, C): A fast, scalable, high performance Gradient Boosting on Decision Trees
